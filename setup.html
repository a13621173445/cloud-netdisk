初始化配置

首次使用前，请完成以下配置。配置信息仅存储在本地浏览器中。
你的 GitHub 账号用户名
用于存储文件和数据的仓库
用于生成验证链接和分享链接，留空则自动推导
需要权限：repo（完整仓库访问）
生成地址：GitHub Settings → Developer settings → Personal access tokens → Tokens (classic)
已有配置？前往登录

部署步骤

1. Fork 或创建仓库到你的 GitHub 账号
2. 在仓库 Settings → Pages 中启用 GitHub Pages
3. 在仓库 Settings → Secrets 中添加邮件配置：
SMTP_SERVER - SMTP 服务器地址 SMTP_PORT - SMTP 端口（如 465） SMTP_USERNAME - SMTP 用户名 SMTP_PASSWORD - SMTP 密码/授权码 SMTP_FROM - 发件人邮箱
4. 生成 GitHub Token 并填写上方表单
5. 保存配置后即可使用
